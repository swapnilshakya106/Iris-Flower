# Iris-Flower
A beginner Machine Learning project that classifies Iris flowers by species using K-Nearest Neighbors and scikit-learn.

 Iris Flower Classifier (Machine Learning)

A beginner Machine Learning project that trains a model to predict the species of an Iris flower (setosa, versicolor, or virginica) based on its measurements — sepal length, sepal width, petal length, and petal width.

What it does:

Loads the classic Iris dataset (built into scikit-learn).
Splits the data into a training set (80%) and a testing set (20%).
Trains a K-Nearest Neighbors (KNN) classifier on the training data.
Checks the model's accuracy on the test data.
Lets you enter your own flower measurements and get a predicted species.

How to Run:

Make sure Python is installed.

Install the required library:

   pip install scikit-learn
   
Run the script:

   python iris_classifier.py
   
Enter measurements when prompted, and see the predicted flower species.

Concepts Used:

Loading a built-in dataset
Train/test split
K-Nearest Neighbors (KNN) classification
Model accuracy evaluation
Making predictions on new data
